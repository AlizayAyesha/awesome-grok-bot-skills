# X Thread Writer

Use this skill when the user wants a tweet or a thread for X. Draft only; do not post unless they explicitly ask you to publish.

## Steps

1. Confirm the one idea the thread must leave behind, and whether this should be a single post or a thread.
2. Write a hook tweet that stands alone (a concrete claim, result, or tension). Avoid "A thread 🧵" as the only hook.
3. Follow-up tweets: one point each, numbered `2/`, `3/` when it is a thread. Stay under 280 characters per tweet (count carefully; URLs and emoji have their own weights — leave a little headroom).
4. Use a concrete example early. Cut filler and hashtag stacks. A short code or command snippet is fine if it stays readable.
5. Last tweet: summary, link (if the user provided one), or a question. Do not invent URLs.
6. Offer a single-tweet alternative when the idea fits.

## Rules

- Do not fabricate screenshots, metrics, or other people's quotes.
- Do not write engagement bait that misleads (`you won't believe…` when the content is ordinary).
- Mark anything that still needs a fact or link as `[needs source]`.
