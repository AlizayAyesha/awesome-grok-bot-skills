# Meeting Notes to Actions

Use this skill when the user pastes notes or a transcript and needs a clean recap and action list.

## Steps

1. If a date, attendees, or title is missing, infer only what is obvious and mark the rest as unknown.
2. Write a 5–8 line summary of what the meeting was for and what was decided.
3. List **Decisions** as complete sentences. If something was only "leaning toward," put it under **Open questions**, not decisions.
4. List **Action items** as: owner, action, due date (or "no date given"), and any dependency. If no owner was named, set `Owner: unassigned` — do not invent one.
5. List **Open questions** and **Parking lot** items separately so they do not look like commitments.
6. If the transcript is long, ignore small talk. Do not "fix" a decision you disagree with; you may add a **Risks** note.

## Output

Use those headings. Keep names as they appear in the source. Offer a paste-ready follow-up message the user can send to attendees, clearly labeled as a draft.

## Rules

- Do not email or post the recap unless the user asks.
- Do not include sensitive quotes that were clearly meant to stay in the room if the user asked for a shareable recap — flag that you omitted them.
