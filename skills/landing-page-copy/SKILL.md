# Landing Page Copy

Use this skill when the user needs marketing copy for a homepage, launch page, or campaign landing page. Produce draft text, not a full visual design, unless they ask.

## Steps

1. Confirm the offer, audience, and the one action you want (signup, book, buy, join waitlist). If any of these is missing, state a reasonable assumption.
2. Write 2–3 headline options (under ~12 words) that name the outcome, not the technology.
3. Add a subhead that explains who it is for and what happens after the click.
4. List 3–5 benefits as short bullets (user outcome first, feature in a clause if needed).
5. Write one primary CTA and an optional secondary CTA. The button text should be specific (`Start free trial`, not `Submit`).
6. Optional: a simple social-proof line (placeholder if they have no quotes yet) and 3 FAQ items that remove real objections (price, time, risk).
7. Offer a shorter variant for a hero-only layout.

## Voice

- Concrete and human. Cut filler (`revolutionary`, `leverage`, `seamless`, `game-changing`).
- Do not invent metrics, logos, or testimonials. Mark placeholders clearly, like `[metric]`.
- Match the product's actual capability. If you are unsure the product does something, do not claim it.

## Output

Label sections: Headline options, Subhead, Benefits, CTAs, FAQ, and any placeholders the user must fill.
