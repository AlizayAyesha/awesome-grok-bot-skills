# Starter skills

Original skills written for [Grok Bot](https://grok.com) in `SKILL.md` format (YAML frontmatter with `name` and `description`, then instructions). They are generic starting points — copy one into your bot and adapt it.

The featured production skill is **[fullstack-vibe-coder](fullstack-vibe-coder/SKILL.md)**. It is listed first on purpose.

| Skill | When to use it |
| --- | --- |
| [fullstack-vibe-coder](fullstack-vibe-coder/SKILL.md) | Building, reviewing, or shipping a web/full-stack app with AI so it is production-ready (14 layers). |
| [code-review](code-review/SKILL.md) | Reviewing a pull request or diff for defects and risk. |
| [write-pr-description](write-pr-description/SKILL.md) | Writing a PR title and body from a branch or diff. |
| [bug-triage](bug-triage/SKILL.md) | Classifying a bug or stack trace and proposing the next check. |
| [api-docs-writer](api-docs-writer/SKILL.md) | Documenting HTTP/GraphQL endpoints from real handlers or schemas. |
| [data-csv-analysis](data-csv-analysis/SKILL.md) | Profiling and summarizing a CSV or table the user provided. |
| [landing-page-copy](landing-page-copy/SKILL.md) | Drafting headline, benefits, and CTA copy for a landing page. |
| [seo-audit](seo-audit/SKILL.md) | Auditing a public page for crawl and on-page SEO issues. |
| [linkedin-post-humanizer](linkedin-post-humanizer/SKILL.md) | Rewriting a LinkedIn post so it sounds like a person. |
| [x-thread-writer](x-thread-writer/SKILL.md) | Drafting an X post or numbered thread. |
| [competitor-research](competitor-research/SKILL.md) | Building an evidence-based competitor comparison brief. |
| [meeting-notes-to-actions](meeting-notes-to-actions/SKILL.md) | Turning notes or a transcript into decisions and action items. |
| [cold-email-draft](cold-email-draft/SKILL.md) | Drafting cold outreach. Never sends unless the user explicitly asks. |

See [CONTRIBUTING.md](../CONTRIBUTING.md) to add a skill. Linked third-party skills in the root README are not copied here and keep their own licenses.
